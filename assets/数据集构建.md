# 数据集构建
进一步简化数据集的情况，重新构建数据集
## 限制
* $FOV=65$
* $yaw\in[-180,180]$
* 不在使用固定pitch，$pitch\in[-30,30]$
* 除负样本外
    * $yaw diff\in[-60,60]$
    * $pitch diff\in[-45,45]$
## 任务分类
按图片B相对图片A的关系分为五类，四类为正常相对关系，一类为负样本\
**每种分类仅在yaw或pitch上存在差值**

1. Up, yaw diff=0, pitch diff>0
2. Down, yaw diff=0, pitch diff<0
3. Left, yaw diff>0, pitch diff=0
4. Right, yaw diff<0, pitch diff=0
5. Unknown, yaw diff>90, -30\<pitch diff\<30

## 难度分类
根据视角差大小，标注一个任务难度分类，不参与训练，仅参与评价
* Easy, $abs(yaw diff)\in[0,15)$ 或 $abs(pitch diff)\in[0,15)$
* Middle, $abs(yaw diff)\in[15,45)$ 或 $abs(pitch diff)\in[15,30)$
* Hard, $abs(yaw diff)\in[45,60)$ 或 $abs(pitch diff)\in[30,45)$
* Unknow, 全部负样本难度均为Unknown

## 样本数量
对于每张全景图，正常相对关系的图片，每种分类共50张，负样本20张

## 训练、验证、测试样本划分

* 其余随机划分为训练与验证集
