# 数据介绍
现有一批分类任务测试样本，其经softmax处理后的预测结果保存在softmax_test.csv文件中，每一行是一对样本，取前4类的softmax结果（softmax_0~3）。每一个softmax_test.csv文件对应一个深度学习模型的输出结果，共有M个（输入时给出包含各csv文件路径的list）。
目的：寻找结果在各模型间差异最大的N个样本，
# 具体方法：
寻找N个样本，将这些数据整理成[M, 4N]的矩阵（检查camera_uuid,room,frame_num_a,frame_num_b的值以确保样本对应），通过SVD计算这个矩阵的奇异值\sigma，使其尽可能满足下面的条件：
$$\max_{S}\; J(S)
   = \underbrace{\sigma_{\min}(A_S)}_{\text{差异强度}}
     \;-\;\lambda\,
     \underbrace{\Bigl(\tfrac{\sigma_{\max}(A_S)}{\sigma_{\min}(A_S)}-1\Bigr)}_{\text{均衡惩罚}}
$$     
即使得结果矩阵在差异尽可能大的情况下，避免某一个模型独占差异。具体实现可使用贪心或其他搜索算法。下面是可参考的伪代码：
```
S = []                       # 选中的样本索引
while len(S) < N_desired:
    best_gain = -inf
    best_x    = None
    for x in remaining_pool:
        S_try = S + [x]
        A_try = build_matrix(models, S_try)  # M x |S_try|
        s = np.linalg.svd(A_try, compute_uv=False)   # 奇异值降序
        sigma_min = s[-1]
        sigma_max = s[0]
        J = sigma_min - λ * (sigma_max / sigma_min - 1)
        if J > best_gain:
            best_gain, best_x = J, x
    S.append(best_x)
    remaining_pool.remove(best_x)
```
